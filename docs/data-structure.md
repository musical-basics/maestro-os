# Database Schema & Data Structure: Maestro OS

> **Database:** Local SQLite (`better-sqlite3`)
> **Format:** Relational SQL with strictly typed TypeScript interfaces for the Electron IPC bridge.

---

## 1. Core TypeScript Interfaces (Frontend <-> IPC)

```typescript
export interface Snippet {
  id: string;               // UUID
  title: string;            // e.g., "Sad Piano Arpeggio"
  filePath: string;         // Local absolute path: /Users/name/Music/Memos/memo.m4a
  assetType: 'audio' | 'midi' | 'sheet' | 'video';
  keySignature: string | null;
  bpm: number | null;
  createdAt: string;        // ISO timestamp
}

export interface Project {
  id: string;               // UUID
  title: string;            // e.g., "Neon Sonata"
  currentStageId: number;   // 1 through 15
  masterDirectory: string;  // Local absolute path: /Users/name/Music/Maestro/Neon_Sonata/
  lastTouchedAt: string;    // ISO timestamp (updated by chokidar file watcher)
  createdAt: string;        // ISO timestamp
}

export interface ProjectAsset {
  id: string;               // UUID
  projectId: string;        // FK -> projects
  stageId: number;          // FK -> pipeline_stages
  filePath: string;         // Local absolute path to the specific asset
  assetType: string;        // e.g., '.logicx', '.wav', '.mp4'
  lastModified: string;     // ISO timestamp
}
```

## 2. SQLite Tables & Relationships

### Table: `snippets`

The holding pen for all unassigned creative raw material.

| Column | Type | Constraint | Description |
|--------|------|------------|-------------|
| `id` | TEXT | PRIMARY KEY | UUID generated by `Node.crypto` |
| `title` | TEXT | NOT NULL | — |
| `file_path` | TEXT | NOT NULL UNIQUE | Absolute local path |
| `asset_type` | TEXT | NOT NULL | — |
| `key_signature` | TEXT | — | — |
| `bpm` | INTEGER | — | — |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | — |

---

### Table: `projects`

The master tracker for active compositions.

| Column | Type | Constraint | Description |
|--------|------|------------|-------------|
| `id` | TEXT | PRIMARY KEY | UUID |
| `title` | TEXT | NOT NULL | — |
| `current_stage_id` | INTEGER | NOT NULL DEFAULT 1 | Maps to the 15 stages |
| `master_directory` | TEXT | NOT NULL | The generated local folder for this project |
| `last_touched_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | — |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | — |

---

### Table: `project_snippets` (Many-to-Many Junction)

Allows one Project to be built from multiple Snippets, and one Snippet to be used in multiple Projects.

| Column | Type | Constraint | Description |
|--------|------|------------|-------------|
| `project_id` | TEXT | NOT NULL | FK → `projects.id` |
| `snippet_id` | TEXT | NOT NULL | FK → `snippets.id` |
| — | — | PRIMARY KEY (`project_id`, `snippet_id`) | Prevents duplicate links |

---

### Table: `pipeline_stages` (Lookup / Enum Table)

Defines the 15 rigid stages and what "Asset Gate" is required to unlock the next stage.

| Column | Type | Constraint | Description |
|--------|------|------------|-------------|
| `id` | INTEGER | PRIMARY KEY | 1 through 15 |
| `stage_name` | TEXT | NOT NULL | e.g., "Audio Editing", "Mixing" |
| `gate_requirement` | TEXT | — | e.g., `.wav`, `.logicx`, `.mp4` (NULL for conceptual stages like "Practicing") |

---

### Table: `project_assets`

Tracks the specific files uploaded/linked to satisfy the Asset Gates.

| Column | Type | Constraint | Description |
|--------|------|------------|-------------|
| `id` | TEXT | PRIMARY KEY | UUID |
| `project_id` | TEXT | NOT NULL | FK → `projects.id` |
| `stage_id` | INTEGER | NOT NULL | FK → `pipeline_stages.id` |
| `file_path` | TEXT | NOT NULL | Absolute local path |
| `asset_type` | TEXT | NOT NULL | Extension type |
| `last_modified` | DATETIME | NOT NULL | — |
